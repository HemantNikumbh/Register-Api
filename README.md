# Register API

A simple and beginner-friendly user registration API built using **Node.js**, **Express.js**, and **MongoDB**. This API securely stores user data with hashed passwords and provides a foundation for further enhancements like user login, authentication, and more.

---

## Features

- User registration with validation
- Password hashing for secure storage
- API response with success or error messages
- MongoDB for data storage

---

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- bcrypt.js (for password hashing)
- dotenv (for environment variables)
